# 🪐 Saturn Romantic Couple Gift

Proyek ini membuat hadiah pasangan bertema Saturnus yang bisa bergerak dan memancarkan suasana romantis. Komponen utama:

- Motor DC kecil (menggerakkan model Saturnus/asing)
- LED ring (WS2812 / NeoPixel) untuk efek cahaya warna Saturnus dan suasana romantis
- Arduino (Uno/Nano) atau papan kompatibel
- Backend Node.js (opsional) untuk kontrol via smartphone
- Frontend web sederhana untuk mengontrol kecepatan, warna, dan pola

Fitur:
- Putar/berhenti motor
- Kontrol kecepatan
- Kontrol warna LED (color picker)
- Pola romantis (pulsing, slow fade)
- Kirim pesan singkat yang diterjemahkan ke pola lampu

Struktur repo:

- /firmware - kode Arduino
- /web-app - frontend & backend server
- /documentation - panduan assembly dan BOM

Lihat dokumentasi untuk langkah pemasangan dan koneksi wiring.
